# Proyecto Módulo de Recibos de Pago (MVC)

Sistema web desarrollado bajo arquitectura Modelo-Vista-Controlador (MVC) en PHP para la gestión y control de recibos de pago.

## 🛠️ Tecnologías utilizadas
* **PHP** (Estructura MVC)
* **CSS / JavaScript**
* **SQL** (Base de datos)

## 📂 Estructura del Proyecto
* `aplicación/`: Contiene los controladores, modelos y vistas.
* `config/`: Archivos de configuración y conexión a la base de datos.
* `público/`: Archivos públicos de acceso web (assets, index).

## 🗄️ Base de Datos
El repositorio incluye los archivos de respaldo necesarios:
* `app_login.sql`
* `app_proyecto_db.sql`
